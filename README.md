# Number Guessing Game

## Project Overview

This is a small, interactive number guessing game that runs in a web browser. It was created as a university assignment to practice building a web page with HTML, styling it with CSS, and adding interactive behavior with JavaScript.

At the start of each game, the program randomly chooses a secret number from 1 to 50. The player has five attempts to find it. After each incorrect guess, the game provides a hint indicating whether the guess was too high or too low. The remaining attempts are shown on the page. Guess correctly to see the win screen; use all five attempts and the game reveals the secret number on the loss screen. Either screen provides an option to start a new game.

## How to Play

1. Open the game in a web browser.
2. Enter a whole number from 1 to 50.
3. Select **Guess** or press **Enter** to submit it.
4. Follow the hint and try again while attempts remain.
5. Choose **Play again** or **Try again** to restart.

## Technologies

- **HTML** provides the game interface.
- **CSS** styles the page and game result screens.
- **JavaScript** selects the secret number, validates guesses, tracks attempts, and controls the game flow.

## Run Locally

No installation or build tools are required. Open `index.html` in a web browser to play.
